08 General algebraic systems

Universal algebra

What is true of every system of operations and equations, whether it is arithmetic or something stranger?

Universal algebra studies algebraic structures in general: a set together with any collection of operations, such as the multiplication of a group or the join and meet of a lattice. Instead of treating groups, rings and lattices one kind at a time, it asks what holds for all such structures and how classes of them defined by equations behave.

The basic constructions are subalgebras, homomorphic images, products, and quotients by congruences. A central theme is that properties of the congruence lattices of all algebras in a class correspond to the existence of terms satisfying certain identities. The area overlaps with logic, lattice theory and category theory, and it now supplies the main tools for classifying the complexity of constraint satisfaction problems.

Groups by equations, fields not

A group can be described as a set with a binary product, a unary inverse and a constant eee satisfying the identities x(yz)=(xy)zx(yz)=(xy)zx(yz)=(xy)z, xe=xxe=xxe=x and xx−1=exx^{-1}=exx−1=e. Because only identities are used, subgroups, quotients and products of groups are again groups. Fields cannot be described this way, whatever operations are chosen: the product Q×Q\mathbb{Q}\times\mathbb{Q}Q×Q is not a field, since (1,0)⋅(0,1)=(0,0)(1,0)\cdot(0,1)=(0,0)(1,0)⋅(0,1)=(0,0) although neither factor is zero.

Central objects

Signature
A list of operation symbols, each with a fixed number of arguments.
Algebra
A set together with one operation for each symbol of a signature.
Homomorphism
A map between algebras of the same signature that respects every operation.
Congruence
An equivalence relation compatible with all operations, so that the quotient is again an algebra.
Variety
The class of all algebras of a signature that satisfy a given set of identities.
Free algebra
The most general algebra in a variety on a given set of generators.
Clone
A set of operations on a set that contains the projections and is closed under composition.

Landmark theorems

  1. Homomorphism theorem

    If f ⁣:A→Bf\colon A\to Bf:A→B is a surjective homomorphism of algebras, then θ={(a,a′):f(a)=f(a′)}\theta=\{(a,a') : f(a)=f(a')\}θ={(a,a′):f(a)=f(a′)} is a congruence of AAA, and the quotient A/θA/\thetaA/θ is isomorphic to BBB.

  2. Birkhoff's variety theorem1935

    A class of algebras of one signature is the class of all models of some set of identities if and only if it is closed under homomorphic images, subalgebras and arbitrary direct products.

  3. Completeness of equational logic1935

    An identity holds in every algebra satisfying a set Σ\SigmaΣ of identities if and only if it can be derived from Σ\SigmaΣ by reflexivity, symmetry, transitivity, substitution of terms for variables, and replacement of equal subterms.

  4. Birkhoff's subdirect representation theorem1944

    Every algebra is isomorphic to a subdirect product of subdirectly irreducible algebras.

  5. Maltsev's theorem1954

    In a variety VVV, the congruences of every algebra commute under composition if and only if there is a ternary term ppp for which the identities p(x,y,y)=xp(x,y,y)=xp(x,y,y)=x and p(x,x,y)=yp(x,x,y)=yp(x,x,y)=y hold in VVV.

  6. Jónsson's lemma1967

    Let VVV be the variety generated by a class KKK of algebras, and suppose every algebra in VVV has a distributive congruence lattice. Then every subdirectly irreducible algebra in VVV is a homomorphic image of a subalgebra of an ultraproduct of members of KKK.

Open problems and frontiers

  • Finite lattice representation problem

    Is every finite lattice isomorphic to the lattice of congruences of some finite algebra?

  • Infinite-domain constraint satisfaction

    Whether the split of constraint satisfaction problems into polynomial-time and NP-complete ones, proved for finite templates, extends to a natural class of infinite templates.
