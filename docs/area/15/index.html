15 Linear and multilinear algebra; matrix theory

Linear algebra

How do you solve a thousand linear equations at once, and what does a matrix do to space?

Linear algebra studies vector spaces and the linear maps between them, together with the matrices that represent those maps. Its starting point is the solution of systems of linear equations. From there it moves to determinants, eigenvalues, canonical forms of matrices, inner products, and bilinear and multilinear forms, including tensors.

Nearly every part of mathematics reduces some of its problems to linear ones, so the area serves as a common language. The basic theory over a field is classical. Current work concerns special classes of matrices, matrix inequalities, tensors and matrices over rings. Computation with large matrices is central to science, engineering, statistics and machine learning.

Central objects

Vector space
A set of vectors that can be added together and multiplied by scalars from a field.
Linear map
A map between vector spaces that respects addition and scalar multiplication.
Matrix
A rectangular array of numbers that represents a linear map in chosen bases.
Determinant
A number attached to a square matrix; it is nonzero exactly when the matrix is invertible.
Eigenvalue and eigenvector
A scalar λ\lambdaλ and nonzero vector vvv with Av=λvAv=\lambda vAv=λv.
Bilinear form
A scalar-valued function of two vectors that is linear in each; inner products are examples.
Tensor product
The vector space through which every bilinear map on a pair of spaces factors uniquely.

Landmark theorems

  1. Rank-nullity theorem

    If T ⁣:V→WT\colon V\to WT:V→W is a linear map and VVV is finite-dimensional, then dim⁡ker⁡T+dim⁡im⁡T=dim⁡V\dim\ker T+\dim\operatorname{im}T=\dim VdimkerT+dimimT=dimV.

  2. Cayley-Hamilton theorem1858

    Let AAA be a square matrix over a commutative ring and p(t)=det⁡(tI−A)p(t)=\det(tI-A)p(t)=det(tI−A) its characteristic polynomial. Then p(A)=0p(A)=0p(A)=0. Cayley stated the theorem in 1858 and verified small cases; Frobenius gave a general proof in 1878.

  3. Spectral theorem

    Every real symmetric matrix AAA can be written A=QΛQTA=Q\Lambda Q^{T}A=QΛQT with QQQ orthogonal and Λ\LambdaΛ real diagonal. Likewise every complex Hermitian matrix is diagonalized by a unitary matrix and has real eigenvalues.

  4. Jordan normal form1870

    Every square matrix over an algebraically closed field is similar to a block diagonal matrix of Jordan blocks, and the blocks are unique up to their order.

  5. Singular value decomposition

    Every real m×nm\times nm×n matrix AAA can be written A=UΣVTA=U\Sigma V^{T}A=UΣVT, with UUU and VVV orthogonal and Σ\SigmaΣ an m×nm\times nm×n matrix that is zero off the diagonal and has nonnegative diagonal entries. Those entries are determined by AAA up to order.

  6. Perron's theorem1907

    A square real matrix with all entries positive has a positive eigenvalue rrr that is a simple root of the characteristic polynomial and exceeds the absolute value of every other eigenvalue. It has an eigenvector for rrr with all entries positive.

    Can two n×nn\times nn×n matrices be multiplied using about n2n^2n2 arithmetic operations, up to a factor nεn^{\varepsilon}nε? The best known exponent is below 2.38.

  • Hadamard conjecture

    For every multiple nnn of 4 there is an n×nn\times nn×n matrix with entries ±1\pm1±1 whose rows are pairwise orthogonal.
