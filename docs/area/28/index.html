28 Measure and integration

Measure and integration

What is the length of a set too scattered to draw, and which sets can be given a size at all?

Measure theory makes precise the idea of size: length, area, volume, mass and probability. A measure assigns a number to each set in a suitable family, so that the size of a union of countably many disjoint pieces is the sum of their sizes. On this base it builds the Lebesgue integral, which applies to far more functions than the Riemann integral of calculus.

The decisive feature is good behavior under limits: under mild conditions, the integral of a limit of functions is the limit of the integrals. This makes spaces of integrable functions complete, a property on which functional analysis, Fourier analysis and partial differential equations rely. Probability theory is measure theory with total mass one. Geometric measure theory extends the ideas to fractal sets and to surfaces with singularities.

The rationals take up no room

List the rational numbers in [0,1][0,1][0,1] as q1,q2,q3,…q_1,q_2,q_3,\dotsq1​,q2​,q3​,… and cover qnq_nqn​ by an interval of length ε/2n\varepsilon/2^nε/2n. The total length used is at most ε(12+14+18+⋯ )=ε\varepsilon\left(\tfrac12+\tfrac14+\tfrac18+\cdots\right)=\varepsilonε(21​+41​+81​+⋯)=ε. Since ε\varepsilonε can be as small as we like, the rationals have Lebesgue measure 0. So the function that is 1 at rational points and 0 elsewhere has Lebesgue integral 0, although it has no Riemann integral.

Central objects

Sigma-algebra
A family of sets closed under complements and countable unions; the sets that get a size.
Measure
A countably additive assignment of nonnegative sizes to the sets of a sigma-algebra.
Lebesgue measure
The standard measure on Rn\mathbb{R}^nRn, extending length, area and volume.
Measurable function
A function for which the preimage of every interval is a measurable set.
Lebesgue integral
An integral defined by slicing the range of a function instead of its domain.
Almost everywhere
Said of a property that holds outside a set of measure zero.
Hausdorff dimension
A notion of dimension, possibly not an integer, that applies to arbitrary subsets of a metric space.

Open problems and frontiers

  • Kakeya conjecture

    A compact set in Rn\mathbb{R}^nRn containing a unit segment in every direction has Hausdorff dimension nnn. Proved in the plane; a proof for n=3n=3n=3 was announced in 2025; open for n≥4n\ge 4n≥4.

  • Falconer's distance conjecture

    If a compact set in Rd\mathbb{R}^dRd, d≥2d\ge 2d≥2, has Hausdorff dimension above d/2d/2d/2, then its set of distances has positive Lebesgue measure.

  • Erdős similarity problem

    Is there, for every infinite set of real numbers, a set of positive Lebesgue measure that contains no scaled and shifted copy of it?
