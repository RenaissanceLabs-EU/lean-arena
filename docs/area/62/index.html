62 Statistics

Statistics

How much can a sample of a thousand people tell you about a population of millions?

Statistics is the study of how to learn from data in the presence of variation and uncertainty. Given observations, it asks which explanations are plausible, how to estimate unknown quantities and how sure one can be of the answers. It also covers how to collect data well, through the design of experiments and of sample surveys.

The mathematical side rests on probability: data are modeled as random draws from a distribution that is only partly known. Estimators and tests are then judged by their error rates, either for a fixed sample size or as the sample grows. Frequentist and Bayesian approaches differ in how they treat unknown parameters. Statistics draws on optimization, linear algebra and computation, and underlies much of machine learning.

Central objects

Statistical model
A family of probability distributions, one of which is assumed to have produced the data.
Estimator
A rule that turns data into a guess for an unknown quantity.
Likelihood
The probability or density of the observed data, viewed as a function of the unknown parameter.
Hypothesis test
A rule for deciding whether data are compatible with a stated hypothesis, with controlled error rates.
Confidence interval
A data-dependent interval that covers the true parameter with a stated probability.
Sufficient statistic
A summary of the data that retains all information about the parameter.
Posterior distribution
In Bayesian inference, the distribution of the parameter after combining a prior with the data.

  2. Neyman-Pearson lemma1933

    For testing one fully specified distribution against another, a test that rejects when the likelihood ratio exceeds a threshold and accepts when it is below has the greatest probability of correctly rejecting among all tests whose level does not exceed its own.

  3. Cramér-Rao bound

  4. Rao-Blackwell theorem

    If an unbiased estimator with finite variance is replaced by its conditional expectation given a sufficient statistic, the result is an unbiased estimator whose variance is no larger.

  5. Glivenko-Cantelli theorem1933

    For independent observations from a common distribution, the empirical distribution function converges uniformly to the true distribution function, almost surely.

Open problems and frontiers

  • High-dimensional inference

    Finding reliable estimates and error statements when the number of unknown parameters is comparable to or exceeds the number of observations.

  • Statistical-computational gaps

    For problems such as detecting a small planted structure in noise, can efficient algorithms reach the accuracy that is statistically possible?

  • Inference after model selection

    Producing valid tests and intervals when the same data were used to choose the model.
