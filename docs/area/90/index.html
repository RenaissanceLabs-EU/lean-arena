Operations research

What is the cheapest way to route a thousand deliveries, or the best mix of products to make?

Operations research uses mathematical models to make decisions about complex systems: how to schedule crews, route vehicles, manage inventories, or locate warehouses. Mathematical programming is its core. One seeks the values of decision variables that make an objective, such as cost or profit, as good as possible while satisfying a set of constraints.

Problems are sorted by structure. Linear programs can be solved at very large scale. Convex programs keep most of that tractability. Problems with integer variables or nonconvex functions are usually hard in the worst case and are attacked by branch-and-bound, cutting planes, relaxations and heuristics. Duality, which pairs each problem with a second one that bounds it, runs through the whole area. Uncertainty leads to stochastic and dynamic programming.

A small linear program

Maximize x+2yx + 2yx+2y subject to x+y≤4x + y \le 4x+y≤4, x+3y≤6x + 3y \le 6x+3y≤6, x≥0x \ge 0x≥0, y≥0y \ge 0y≥0. The feasible region is a quadrilateral with corners (0,0)(0,0)(0,0), (4,0)(4,0)(4,0), (3,1)(3,1)(3,1) and (0,2)(0,2)(0,2). The objective takes the values 000, 444, 555 and 444 there, so the maximum is 555 at (3,1)(3,1)(3,1). A linear objective over such a region always attains its best value at a corner.

Central objects

Objective function
The quantity to be minimized or maximized.
Feasible set
The set of all choices of the variables that satisfy the constraints.
Linear program
An optimization problem with a linear objective and linear equality and inequality constraints.
Convex function
A function whose graph lies below its chords, so that every local minimum is global.
Dual problem
A companion optimization problem whose value bounds that of the original.
Integer program
An optimization problem in which some variables must take integer values.
Network flow
An assignment of amounts to the edges of a graph that respects capacities and conserves flow at nodes.

    If a linear program has an optimal solution, then so does its dual, and the two optimal values are equal.

    A linear program with rational data can be solved in time polynomial in the number of bits needed to write it down. The first proof used the ellipsoid method.

Open problems and frontiers

  • Strongly polynomial linear programming

    Is there an algorithm for linear programming whose number of arithmetic operations is polynomial in the number of variables and constraints alone?

  • Polynomial Hirsch conjecture

    Is the diameter of the graph of every polytope bounded by a polynomial in its dimension and number of facets?

  • Four-thirds conjecture

    Is the optimal traveling salesman tour in a metric space always at most 4/3 times the value of the subtour linear programming relaxation?
