03 Mathematical logic and foundations

Logic and foundations

Can every true statement about whole numbers be proved, and what can no computer ever decide?

Mathematical logic studies mathematical reasoning itself. It asks what a proof is, which statements follow from which axioms, what it means for a statement to be true in a structure, and what can be computed by a mechanical procedure. Its main branches are model theory, computability theory, set theory and proof theory.

The method is to treat statements and proofs as precise finite objects and then prove theorems about them. Set theory supplies a common foundation for the rest of mathematics, and model theory has produced results in algebra and number theory. Computability theory is the starting point of theoretical computer science, and proof theory compares the strength of axiom systems.

A number beyond all numbers

Take all true first-order statements about the natural numbers and add a new symbol ccc with the axioms c>0c>0c>0, c>1c>1c>1, c>2c>2c>2, and so on. Any finite set of these axioms holds in the ordinary natural numbers if ccc is read as a large enough number. By the compactness theorem, all of them hold together in some structure. It obeys every first-order truth of arithmetic, yet it contains an element above every ordinary number.

Central objects

First-order formula
A statement built from variables, relations and functions using and, or, not, for all and there exists.
Structure
A set with chosen relations and functions, in which formulas are true or false.
Formal proof
A finite sequence of formulas, each an axiom or obtained from earlier ones by a fixed rule.
Computable function
A function on natural numbers whose values a Turing machine can calculate.
ZFC
The Zermelo-Fraenkel axioms for sets with the axiom of choice, the usual foundation of mathematics.
Ordinals and cardinals
Numbers that extend counting to the order type and the size of infinite sets.
Forcing
A technique for building new models of set theory, used to prove independence results.

Landmark theorems

  1. Gödel's completeness theorem1929

    Let TTT be a set of first-order sentences and φ\varphiφ a sentence. Then φ\varphiφ is true in every model of TTT if and only if there is a formal proof of φ\varphiφ from TTT.

  2. Compactness theorem

    A set of first-order sentences has a model if every finite subset of it has a model.

  3. Löwenheim-Skolem theorem

    If a first-order theory in a countable language has an infinite model, then it has a model of every infinite cardinality.

  4. Gödel's first incompleteness theorem1931

    Let TTT be a consistent theory whose axioms can be listed by an algorithm and which contains Robinson arithmetic. Then there is a sentence of arithmetic that TTT neither proves nor refutes. Gödel assumed slightly more than consistency; Rosser removed the extra assumption in 1936.

  5. Undecidability of the halting problem1936

    There is no algorithm that decides, for every Turing machine MMM and input www, whether MMM eventually halts on www.

  6. Independence of the continuum hypothesis1963

    The continuum hypothesis says that every infinite set of real numbers is either countable or of the same cardinality as R\mathbb{R}R. If ZFC is consistent, it neither proves nor refutes this. Gödel showed in 1938 that it cannot be refuted, and Cohen showed in 1963 that it cannot be proved.

Open problems and frontiers

  • Vaught's conjecture

    A complete first-order theory in a countable language has, up to isomorphism, either countably many countable models or as many as there are real numbers.

  • Inner models for large cardinals

    Whether there is a canonical model of set theory, similar to Gödel's constructible universe, that contains a supercompact cardinal.

  • P versus NP

    Whether every problem whose solutions can be checked in polynomial time can also be solved in polynomial time.
