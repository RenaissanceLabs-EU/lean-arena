93 Systems theory; control

Systems and control

How does cruise control hold a car at a steady speed on hills it cannot see coming?

Control theory studies systems that evolve in time and can be influenced through inputs. The goal is to choose the inputs so that the system behaves as desired: an aircraft holds its course, a chemical reactor keeps its temperature, a robot arm follows a path. The key idea is feedback, in which measurements of the current behavior are used continually to correct the input.

A system is described by differential or difference equations with input and output variables. For linear systems there is a complete theory based on linear algebra and complex analysis. Nonlinear, infinite-dimensional and stochastic systems require differential geometry, partial differential equations and probability. Typical questions are whether a state can be reached, whether it can be reconstructed from measurements, and whether a design remains stable under disturbances and modeling errors.

Central objects

State
The set of variables that, with future inputs, determines the future behavior of the system.
Input
A signal chosen by the controller, or imposed from outside, that drives the system.
Feedback
Choosing the input as a function of measured outputs or states.
Transfer function
For a linear time-invariant system, the ratio of the Laplace transforms of output and input.
Controllability
The property that inputs can steer the state from any point to any other in finite time.
Observability
The property that the state can be determined from the inputs and outputs over a time interval.
Lyapunov function
An energy-like function that decreases along trajectories and certifies stability.

    If near an equilibrium of x˙=f(x)\dot x = f(x)x˙=f(x) there is a continuously differentiable positive definite function VVV whose derivative along solutions is nonpositive, the equilibrium is stable. If that derivative is negative definite, the equilibrium is asymptotically stable.

  3. Kalman rank condition1960

    The system x˙=Ax+Bu\dot x = Ax + Bux˙=Ax+Bu with state in Rn\mathbb{R}^nRn is controllable if and only if the matrix [B,AB,…,An−1B][B, AB, \dots, A^{n-1}B][B,AB,…,An−1B] has rank nnn.

  4. Kalman filter1960

    For a linear system driven by Gaussian white noise and observed through linear measurements with Gaussian white noise, the conditional mean of the state given the measurements so far obeys a recursive linear update. It is the estimate with the smallest mean square error.
