94 Information and communication theory, circuits

Information and coding

How can a scratched disc or a noisy phone line still deliver a message without a single error?

Information theory measures information and determines the limits of storing and transmitting it. It asks how far data can be compressed and how fast it can be sent reliably over a channel that introduces errors. Coding theory constructs the error-correcting codes that approach these limits. The area also includes cryptography, signal processing, and the theory of switching circuits and networks.

Shannon's theory is probabilistic: sources and channels are random, and the limits are expressed through entropy and mutual information. Constructing good codes, by contrast, uses algebra and combinatorics, including finite fields, polynomials, algebraic curves and sparse graphs. Cryptography adds number theory and computational complexity. Limits are usually proved by a counting or probabilistic argument, and the hard part is to reach them with efficient explicit schemes.

Central objects

Entropy
The average number of bits needed per symbol to describe the output of a random source.
Channel
A model of a transmission medium, giving the probability of each output for each input.
Mutual information
The amount by which knowing one random variable reduces uncertainty about another.
Channel capacity
The highest rate at which information can be sent over a channel with vanishing error probability.
Error-correcting code
A set of codewords chosen so that the original can be recovered after some symbols are corrupted.
Hamming distance
The number of positions in which two words of equal length differ.
Cipher
A method of scrambling a message with a key so that only key holders can read it.

    A source emitting independent identically distributed symbols with entropy HHH bits can be encoded at any rate above HHH bits per symbol with error probability tending to zero as the block length grows. At any rate below HHH this is impossible.

    A cipher is perfectly secret if the ciphertext is statistically independent of the message. This requires the entropy of the key to be at least the entropy of the message. The one-time pad, with a uniformly random key as long as the message and used once, achieves it.

Open problems and frontiers

  • Capacity of networks

    Determine the capacity of basic multi-user channels, such as the relay channel and the interference channel.

  • Best binary codes

    What is the largest possible rate of binary codes with a given relative minimum distance as the length grows? It is unknown whether the Gilbert-Varshamov bound is optimal.

  • Shannon capacity of the 7-cycle

    Determine the zero-error capacity of the channel whose confusion graph is a cycle of length 7.
